Student Task Tracker

A modern AI-powered Student Task Management application built to help students organize tasks, track deadlines, monitor productivity, and improve performance.

🚀 Features
✅ Add, edit, and delete tasks
📅 Deadline and due-date tracking
📊 Productivity and performance monitoring
🤖 AI-powered assistance using Gemini API
📱 Responsive modern UI
☁️ Cloud deployment support
🔐 Environment-based API key protection
🛠️ Tech Stack
Frontend: React / Next.js
Backend: Node.js
AI Integration: Gemini API
Deployment: Google Cloud Run / AI Studio
Styling: CSS / Tailwind (if used)
📂 Project Setup
Prerequisites
Node.js installed
Gemini API Key
⚙️ Installation

Clone the repository:

git clone https://github.com/your-username/student-task-tracker.git

Move into the project folder:

cd student-task-tracker

Install dependencies:

npm install
🔑 Environment Variables

Create a .env.local file in the root directory and add:

GEMINI_API_KEY=your_gemini_api_key
▶️ Run Locally

Start the development server:

npm run dev
